**Simple LED PCB Design using KiCad**

**Overview***

This project is a beginner-level PCB design created using KiCad. The PCB consists of three LEDs, each connected with a current-limiting resistor and powered through a pin header connector.

**Features**

* Schematic capture using KiCad
* PCB layout and routing
* Through-hole component design
* 3D PCB visualization
* Design Rule Check (DRC) verification

**Components Used**

* 3 × LEDs
* 3 × Resistors
* 1 × Pin Header Connector

**Files**

* `demo.kicad_sch` – Schematic design
* `demo.kicad_pcb` – PCB layout
* `demo.kicad_pro` – KiCad project file
* `demo.kicad_prl` – Project settings
* `demo-backups/` – Backup files
